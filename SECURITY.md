# Security Policy

Nagi OS is a Developer Preview and experimental operating system. It is not
currently a production security boundary and does not provide production
security guarantees.

## Reporting a concern

Do not disclose credentials, private keys, access tokens, personal data, or
other sensitive material in a public issue, pull request, commit, or log.

This repository does not currently publish a dedicated security-reporting
email address or other permanent public contact. If GitHub provides a private
reporting channel for this repository, use that channel. Otherwise, contact
the repository owner through a private GitHub channel and provide only the
minimum information needed to establish a private conversation.

Please include the affected revision, component, reproduction conditions, and
impact assessment only after a private channel is established.

## Supported versions

No production-supported release line is currently declared. The repository
contains an evolving Developer Preview; security fixes and response timing
are not guaranteed.
