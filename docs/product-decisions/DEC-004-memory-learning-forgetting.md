# DEC-004 — Memory保存・学習・自然忘却・再学習

**状態:** CONFIRMED（下記の日数・回数はPROVISIONAL）  
**最終合意:** 2026-10-25までのNagi_chat議論  
**対象:** 0.3  
**関連:** DEC-003、DEC-005

## 確定事項

1. **重要情報を自動的に覚える（選択B）:** Nagiは有用な事実、重要な決定、好み、習慣、継続中の作業をユーザーの毎回の明示指定なしに学習する。会話を無差別に永久保存しない。
2. **自然忘却（選択B）:** 有用性が低く長期間使われないMemoryを Active → Decay → Archive → Delete のライフサイクルで整理する。
3. **保護:** ユーザーが明示的に固定したMemory、継続中の重要なプロジェクト、重要な意思決定、定着した習慣などは単純な経過時間で自動削除しない。判断に迷う場合はArchiveに留める。
4. **自然な再学習:** DecayまたはArchive状態のMemoryは、ユーザーに役立てば再活性化できる。自然忘却で削除した情報は新たな観測から学習してよい。
5. **明示的な忘却は優先:** 「忘れて」と指示されたMemoryを利用対象から直ちに外し、既存履歴・Waybackなどから自動再学習しない。ユーザーが明示的に再開を許した場合は別。
6. **削除範囲の正確さ:** 完全削除を要求した場合はMemory本体、派生要約、索引、Context cacheへ反映する。元ファイル、Activity、Wayback、バックアップ、過去のCloud送信は管理境界が別なので、削除済みと誤表示しない。
7. **習慣の文脈:** 一度の操作だけを習慣としない。繰返しと利用者の採用を根拠に、どのTask・Workspace・用途で好まれたかを学習する。Nagi自身の独断の繰返しだけでユーザーの好みと断定しない。
8. **ユーザー指定を優先:** 「毎回こうして」「もう使わない」という明示指示は、暗黙学習より優先する。習慣は権限を増やさない。
9. **モデル非依存:** Granite、ELYZA、Qwen等を入れ替えてもMemory、Preferences、Habits、Profileを維持する。
