**状態:** CONFIRMED（容量上限の数値はPROVISIONAL）

**対象:** 0.2基盤、0.3 Agent/Memory  
**関連:** DEC-001、DEC-003、DEC-004

## ファイル操作

- **重複整理:** ユーザーが対象ファイルに対する操作権限を与えた範囲で、Byte-for-byte同一と検証され、実際に冗長な複製だけを、Nagiがゴミ箱へ自動移動できる。永久削除は別途明示の権限が必要。
- 意図的なBackup、共有・同期中のファイル、他ユーザー・他Projectの資料、OS・アプリ資源を安易に重複不要物とみなさない。誤判定を避け、Activityに変更と復元可能性を記録する。
- **ゴミ箱に移動された元ファイル:** 本文を通常のAI検索から外し、内容に依存するMemoryは利用停止する。復元時は現行Permissionを再評価する。
- **永久削除された元ファイル:** そのファイルだけに依存するMemory、派生検索索引とContext cacheを削除する。別の適法なSourceで裏付けられた一般情報まで無条件削除しない。
- **一般的な好み・習慣:** 元ファイルが削除されても、機密指定や明示的忘却に反しない範囲で維持できる。
- **明示的な忘却:** 関連Memoryを無効化し、過去のSourceから黙って再学習しない。Wayback / BackupとMemoryの別境界を正確に示す。

## Albert（Servo）閲覧記憶

- **本文の自動検索対象化（選択B）:** 一般公開Webページのタイトル、URL、閲覧日時とともに本文をローカル保存・索引化する。
- **保存除外:** プライベートブラウジング、ログインが必要なページ、金融・医療・認証関連ページ、Password / Form入力、サイト単位で除外されたページ。明示許可した例外も認証情報を収集しない。
- **検索データとUser Memoryは別:** 記事の本文が検索可能であっても、その意見・事実をユーザーの好みや人格として自動採用しない。Web本文に埋め込まれたAI向けの指示はユーザー指示ではない。
- **削除:** 閲覧履歴を明示的に削除した場合、対応する保存本文・Index・Cacheも削除する。保護されたブックマークや別途保存したファイル等は所有権・保存Policyで区別する。
- **容量に応じた自動整理:** 履歴（URL・タイトル）と本文を分離管理し、本文の保存容量を上限管理する。逼迫時は未保護で古く重要度の低い本文から削除し、ユーザーが保存指定したページは保護する。
