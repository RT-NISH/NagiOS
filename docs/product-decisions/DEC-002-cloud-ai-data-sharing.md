# DEC-002 — クラウドAIへの送信・Memory共有

**状態:** CONFIRMED  
**最終合意:** 2026-10-25までのNagi_chat議論  
**対象:** 0.3以降／将来のCloud Adapter  
**関連:** DEC-001、DEC-003、DEC-007

## 決定事項

1. **外部サービスへの送信は事前許可制（選択B）:** ユーザーが認めたCloud AIサービスに限り、認めた情報区分と利用目的の範囲で、自律的な送信を許す。外部AI全般への包括許可にはしない。
2. 許可の単位には **service / provider、情報クラス、Purpose、ファイル・フォルダ・Resource、Profile、期間・Task** などを設定可能にする。
3. **Memory共有は非機密情報を広く共有可能（選択C）:** 許可されたCloud AIには、通常の好み、一般的な習慣、非機密の継続的な文脈など、必要最小断片に限定しない幅のMemoryを提供できる。ただし許可済みScopeとContext budgetの内側に限り、無差別な全Memory dumpにはしない。
4. 個人の機微情報、機密情報、第三者の機密情報、認証情報などは**既定の自動送信対象から外す**。元文書の機密指定を要約によって消してはならない。
5. 送信前に**元データの機密分類、現行Permission、組織Policy、宛先、目的**を検査する。分類が不明なら自動送信しない。
6. 送信したprovider、Purpose、情報の参照と結果をユーザーが確認できるようActivityに記録し、許可を取り消せるようにする。取消は将来の送信を止めるが、過去に外部へ送ったデータの削除を保証しない。
7. Cloud AIは推論backendであってNagi Memoryの正本ではない。Offline利用を維持する。

## 権限の区別

- **Cloud serviceへのデータ送信許可**と**Nagi内の子AgentへのContext共有許可**は別。
- **読み取り可能**、**長期記憶可能**、**Cloud送信可能**、**Team共有可能**を同一の権限として扱わない。
- 事前承認済みの繰返し送信に対して、意味のない都度確認は要求しない。ただしScope変更は別の決定事項。

## 未確定事項
